Research Agent Pipeline

flowchart TD Start((Start)) --> Init[Initialize Agent with Rigid Prompt] Init --> CheckLoop{Task Complete or
Max Steps Reached?} CheckLoop -- Yes --> End((Task Finished)) CheckLoop -- No --> BuildPrompt[Construct Context Prompt
Retrieve past logs if too long] BuildPrompt --> TrackSetup[Start CodeCarbon Tracker
Measure Power] TrackSetup --> LLMCall[Query Local LLM API] LLMCall --> FormatCheck{Valid 6-Section Format
& Valid JSON Tool Input?} FormatCheck -- No --> RetryLimit{Under Max Retries?} RetryLimit -- Yes --> AppendError[Append Error Guidance
to Prompt] --> LLMCall RetryLimit -- No --> Fail((End with Failure)) FormatCheck -- Yes --> StopTrack[Stop CodeCarbon Tracker] StopTrack --> Parse[Parse Action and Input] Parse --> Execute[Execute Tool in Environment] Execute --> ObsCheck{Observation > 5000 chars?} ObsCheck -- Yes --> Sum[Summarize chunks
via secondary LLM call] --> History ObsCheck -- No --> History[Save to History Array] History --> MLog[Summarize Step
& Append to Research Log] MLog --> CheckLoop
